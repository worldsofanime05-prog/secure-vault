☁️ Google Sync

Connect your own Firebase project to sync your encrypted vault across devices. Your passwords remain encrypted — Google only stores the encrypted data.

Create Firebase Project
  1. Go to console.firebase.google.com
  2. Click "Add project" → name it anything → Continue
  3. Disable Google Analytics (not needed) → Create project
  4. Click "Web" icon (</>) to add a web app
  5. Register app with any nickname → skip Firebase Hosting
  6. Copy the firebaseConfig object shown
  7. Paste each value into the fields below
Set up Authentication
  1. Left sidebar → Build → Authentication → Get Started
  2. Sign-in method → Google → Enable → Save
Set up Database
  1. Left sidebar → Build → Firestore Database → Create database
  2. Start in production mode → choose any location → Done
  3. Go to Rules tab → replace everything with:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /securevault_users/{userId} {
      allow read, write: if request.auth != null
        && request.auth.uid == userId;
    }
  }
}
  1. Click Publish
Authorize Your Domain
  1. Go to Authentication → Settings → Authorized domains
  2. Click Add domain → enter your GitHub Pages domain (e.g. yourusername.github.io)
  3. Without this, Google Sign-in will fail with "unauthorized-domain" error
